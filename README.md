# Bliss City Churches Website

Welcome to the official website codebase for **Bliss City Churches**, a vibrant Pentecostal church based in Portlaoise, Ireland.

## Project Structure

- `index.html`: The main homepage of the church.
- `styles.css`: The stylesheet for the website's design.
- `assets/`: A folder containing all images, logos, and media used on the website.

## How to view
Simply open `index.html` in any modern web browser to preview the site.
